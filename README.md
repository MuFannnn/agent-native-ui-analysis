# Agent Native UI Analysis

本仓库整理智能体原生 UI 的参考分析，以及 Miracle_Astock 的前台产品—工程一体化目标设计与交互原型。

## 交互原型

**[Miracle AStock · HTML 交互原型](Miracle_Astock_Prototype.html)**

下载或拉取仓库后，直接用 Edge 或 Chrome 打开 `Miracle_Astock_Prototype.html`。文件自包含，不需要安装依赖、启动服务器或登录。GitHub 文件页面显示源码；下载原始文件后打开即可体验。

原型包含六个一级场景、固定底栏、窗口操作演示、主题与密度、研究输入与对象引用。个人中心底部是“外观与偏好”；研究右上角“我的资产”在展示区内展开文件与产物目录，不另弹资产窗口。

### 看盘与竞价的评审目标

两页都提供平铺、题材、高度、行业、自选、全景六种模式；日期、模式、分类来源和筛选合在一条紧凑工作栏。分类名称沿用韭研、开盘啦、索罗斯，采用统一的圆角控件、弹层和克制选中态。具体归类关系仍为虚构样本，不代表供应方真实数据。

竞价的 09:15、09:20、09:25 使用紧凑阶段标识，与匹配金额、高开数量等摘要同一行。表格是主要工作区域；不额外摆放大标题、PHASE、第一阶段、示例阶段、静态样本说明或单击/双击教学栏。原型边界统一在帮助和本文说明，不占据业务数据区域。全局个人中心、通知预留及选择工具底栏仍保留。

表格按列定义排序依据，未配置则不可排序；支持列宽拖动、显隐、顺序和范围内偏好保存，以及表头/数据行右键和键盘入口。三阶段共用实现，但排序、列宽和列布局按模式、分类来源、阶段分别管理。紧凑模式以 11px 字体、25px 数据行为原型基准，标准模式以 12px、29px 为基准。

### 表格交互与既定体系

**AG Grid 等成熟产品仅用于参考排序、列宽、列设置和右键菜单等基本交互，不是本项目的技术选型、安装任务或架构替代方案。** 继续按照主设计文档的基础表格、领域列定义、数据绑定、视图实例、对象引用与统一应用操作组织。

菜单、工具栏、键盘和原型结构化接口复用同一执行入口，目标包含明确表格和对象身份。列含义、单位、排序值与分类口径由同一份领域定义供显示和语义接口读取。引用保留日期、阶段、来源、行列和原始值，进入研究输入的小卡片；不截图、不自动发送、不新建选区面板。原型接口不代表已经连接真实智能体。

所有行情、证券、商品、作者与研究结果均为虚构示例；模拟分析不调用模型或业务服务，窗口操作不等于 Electron 真实窗口能力。本文件用于布局、视觉和交互评审，不是生产前端或业务验收结果。

后续直接更新同一个 HTML 并提交 Git，不新增版本文件、archive 或备份副本；已确认规则直接修订主设计正文。浏览器交互检查、真实数据接通、模型能力和 Electron 窗口验收分别记录，不能互相替代。

**[Miracle_Astock · 前台产品—工程一体化总设计](Miracle_Astock_FRONTEND_MASTER_DESIGN.md)**

这是当前讨论的唯一主文档。直接修改正文并提交 Git，历史只通过 Git 查看，不另存版本或归档副本。

当前重点是整个前台基础体系：全局布局、一级导航与固定底栏、场景和区域组织、组件职责、状态与任务生命周期、对象引用、配置及视觉规范。产品设计与代码承载同步对应，目标明确后再改造现有代码，不以兼容旧组织方式为约束。

对象选择只是公共能力之一：通过 Ctrl + Shift + 鼠标左键或右下常驻选择工具启用，完成后释放；解析实际对象并在研究会话输入框中以附件式小卡片显示。不将其做成截图功能或独立选区面板。

当前研究对话和临时对话是后续需要支持的业务能力。本轮只保留共享输入与会话目标的接入边界，不前置运行时、存储、删除或清理实现。

文中区分已确认规则、工程建议与后续业务。本仓库维护设计与原型，不据此修改 Miracle_Astock 业务代码或运行资源。
