### 表格交互与既定体系

**AG Grid 等成熟产品仅用于参考排序、列宽、列设置和右键菜单等基本交互，不是本项目的技术选型、安装任务或架构替代方案。** 继续按照主设计文档的基础表格、领域列定义、数据绑定、视图实例、对象引用与统一应用操作组织。不得把参考示例改写成必须引入某个 Grid 或 AI Toolkit 的实施前提。

看盘调整将日期、平铺/题材/高度、题材分类来源合在同一工作栏，并压低统计条。分类名称沿用韭研、开盘啦、索罗斯；原型中的归类关系仍是虚构示例，不能当成实际供应方数据。

表格基础交互包括：按列定义排序依据，未配置则不可排序；列宽拖动、显隐、顺序及范围内偏好保存；表头和数据行的右键菜单。菜单、工具栏、键盘和原型的结构化操作接口复用同一执行入口，目标包含明确表格与对象身份。右键不是另一套业务实现，选择与引用也不是截图。

字段含义、单位、排序值与分类口径由同一份领域定义供显示和语义接口读取；引用进入研究输入的小卡片，不自动发送，不另建选区面板。原型结构化接口只用于本地验证，不表示已经连接真实产品智能体。

所有行情、证券、商品、作者与研究结果均为虚构示例；模拟分析不调用模型或业务服务，窗口操作不等于 Electron 真实窗口能力。本文件用于布局、视觉和交互评审，不是生产前端或业务验收结果。

后续直接更新这个 HTML 文件并提交 Git，不新增版本文件、archive 或备份副本；已确认的产品规则同步修改下面的主设计文档。
